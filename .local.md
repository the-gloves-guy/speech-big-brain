## Base prompt

I am using audio language id models in a deployed environment where only a limited set of languages occur. The problem is that my language id model (speechbrain/lang-id-voxlingua107-ecapa) supports a large number and so we get a lot of false positives. 

I want to compare two different approaches for modifying the model. 
1. Filtering and rescaling before softmax
2. Retraining only the classification head using a filtered set of the existing training set.


I then want to evaluate both these approaches on relevant parts of the Fleurs dataset. I want to compare:
- performance metrics - precision, recall, f1, accuracy
- the calibration of the predictions using ECE
